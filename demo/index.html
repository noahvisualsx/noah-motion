noah-motion

零依赖的小型动画库。闭式弹簧、可以随意拖动的时间轴、几个常用的网页动效，同一份动画既能在网页上播放，也能逐帧导出成视频。

gzip 后约 8KB · TypeScript · 默认照顾“减少动态效果”设置

弹簧

不逐帧模拟，直接解方程：给一个时间，立刻得到位置和速度。拖动下面两个滑块，看曲线怎么变。

import { spring } from 'noah-motion';
const s = spring({ duration: 0.5, bounce: 0.25 });
s(0.2);          // 第 0.2 秒的进度
s.velocity(0.2); // 第 0.2 秒的速度
s.toCSS();       // { easing: 'linear(0, …, 1)', duration: 812 }

时间轴

每个属性写成关键帧轨道，前一段没停稳就换目标也会自然衔接。整个画面是时间的纯函数，拖动进度条可以停在任意一帧。

import { track, timeline, spring } from 'noah-motion';
const w = track(16, [[0.4, 220], [2.2, 120], [3.4, 16]]);
const tl = timeline({ duration: 4, loop: true, target: stage, render(t) {
  shape.style.width = w(t) + 'px';
}});
tl.seek(1.5);

导出视频

同一份时间轴，用命令行逐帧截图，再用 ffmpeg 合成 MP4。每一帧都是算出来的，不会掉帧。

import { exposeForRender } from 'noah-motion';
exposeForRender(tl);
